# Fuellstandsmesser3 V7.4.0 – Hardware

Verbindliche Kurzreferenz:

- ESP32-C3 Super Mini, 4 MB Flash
- SDA GPIO4, SCL GPIO5
- ToF `0x29`
- OLED `0x3C`
- BME280 oder BMP280 `0x76`
- optionale DS3231 `0x68`
- optionales AT24C32 häufig `0x57`, derzeit nicht beschrieben
- Status-LED GPIO8, Displaytaste GPIO9

Ausführliche Verdrahtung: [`../../docs/HARDWARE_WIRING.md`](../../docs/HARDWARE_WIRING.md).
